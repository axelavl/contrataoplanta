# Implementación issue #241

Este documento registra la implementación solicitada para el issue #241.

- Instituciones: limpieza del marcador “Personal Civil” en nombres visibles de instituciones, dejando sólo el nombre base, por ejemplo “Armada de Chile” o “Carabineros de Chile”.
- UI: bordes de cards, widgets, resultados y modal más consistentes.
